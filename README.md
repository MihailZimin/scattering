Краткое пояснение, что за что отвечает:
1) harmonics.py - файл с расчётом сферических гармоник. Гармоники расчитываются по формулам через угловые функции по формулам 4.50 из книги Борена-Хаффмана.
Для расчёта функций Бесселя использую готовые функции, чтобы не бороться с проблемами сходимости и точности их вычисления (можно было и самому их написать по пояснениям
главы 4.8 книги, но зачем)
2) coefficients.py - расчёт коэффициентов (пока только a и b). Вычисляю их по формулам 4.88, 4.89, чтобы была численная стабильность.
3) test_functions.py - файл с основными построениями.
Функции pi и tau здесь вычисляю немного другим способом, отличающемся от их же рассчёта в harmonics.py - не знаю
какой удобнее, но делал в разные дни и формулы брал из разных источников.
Интенсивность в зависимости от угла считаю по формулам 4.74
Сечения экстинкции и рассеяния считаю по формулам 4.62 и 4.61 соответственно
Данные о зависимости показателя преломления от длины волны беру из датасета с сайта https://refractiveindex.info/?shelf=main&book=H2O&page=Segelstein
4) main.py - просто файл, где запускаю все функции
